# Zomato Premium Membership

Zomato is planning to offer a **premium membership** to customers who have placed **multiple orders in a single day**.

## Task

Write an SQL query to find those customers who have placed **multiple orders in a single day at least once**, and for each such customer report:

- the **total order value** generated by that customer (across **all** of their orders), and
- the order value generated **only by those orders** that were part of a multi-order day.

Display the results in **ascending** order of **total order value**.

## Schema

### `orders` (primary key: `order_id`)

| Column          | Type        |
|-----------------|-------------|
| `customer_name` | varchar(20) |
| `order_date`    | datetime    |
| `order_id`      | int         |
| `order_value`   | int         |
